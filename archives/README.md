# CAD archive downloads

These archives preserve the original dated CAD folders, source files, geometry, pictures, reports, and original print packages. Each ZIP is independently extractable. To restore a revision completely, download **all** ZIPs listed for it and extract them into the same project root; the archives already contain the original `cad/<revision>/` paths. No split-file joining utility is required.

For the current thruster print parts, use the separate [R14 print kit](R14-Smooth-Frame-Print-Kit.zip) and [assembly guide](../cad/smooth-frame-r14-2026-10-25/ASSEMBLY-AND-PRINT.txt). The full archives also preserve earlier versions and diagnostic exports.

## Integrity and scope

[file-inventory.csv](file-inventory.csv) lists the original relative path, byte length, SHA-256, and containing archive for each CAD file. [archive-manifest.json](archive-manifest.json) lists ZIP sizes and SHA-256 values. All archive entries passed ZIP CRC checks during packaging.

All project revision folders are retained, including the old R4 native export package with two historical meshes absent from the loose-file collection. Local executable tools, Python caches, the unrelated NVIDIA folder, temporary meeting assets, and the repository invitation screenshot are not project deliverables and are excluded.

Browse the original text sources and CAD images in [cad/](../cad/), and read the [motor and fan journal](../docs/journals/motor-and-fan-cad-development.md) for the history and current status.
