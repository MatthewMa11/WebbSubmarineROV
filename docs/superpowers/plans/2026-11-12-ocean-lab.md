# Ocean Lab implementation plan

**Goal:** Add three playable marine experiences and integrate them into the ROV website.
**Architecture:** Native HTML controls and SVG scenes, a pure state model for depth and training behavior, and a separate canvas module for glow art. Reuse existing ocean theme, navigation, and motion preference.
**Tech stack:** Buildless HTML/CSS/JS modules; Node's native test runner; GitHub Pages.
**Spec:** `docs/superpowers/specs/2026-11-12-ocean-lab.md`

## Constraints and review focus

- Preserve real project content and source downloads; distinguish simulated activities from vehicle capabilities.
- Depth zone boundaries at 200, 1,000, and 4,000 m; educational absolute pressure estimate of 1 + depth/10 atmospheres.
- Map coordinates bounded to 6–94; recording requires a revealed target within 10 units; scans reveal targets within 34 units; each find records once.
- Check keyboard focus, touch controls, reset behavior, storage restrictions, motion pause, offscreen rendering, and narrow screens.
