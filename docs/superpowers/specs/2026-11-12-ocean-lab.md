# Interactive marine exploration

Extend the existing ocean-themed GitHub Pages website with a dedicated Ocean Lab, linked prominently from the homepage and navigation. Preserve the club's full journal, budgets, CAD assets, and current whale scene.

Build three connected browser experiences: a 0–4,000 m depth explorer with sourced light-zone and pressure facts and selectable illustrated creatures; a fictional ROV training map with steering, sonar, and three finds to document; and a pointer/touch bioluminescence art canvas with adjustable current and colors. Add a sonar response to the homepage whale.

Use existing plain HTML, CSS, JavaScript and SVG. All activity stays in the browser. Mark the training map and art as illustrative. Depth is educational and does not imply the club ROV has a verified 4,000 m rating. Scientific copy links to primary institutional sources.

Keep keyboard and touch controls, mobile layouts, readable journals, and the existing pause/reduced-motion preferences. Limit canvas rendering to visible sections and cap particle count and pixel ratio. Do not hijack page scrolling or start audio automatically.

Approach: extend the current static site with focused modules, rather than adding a game framework or backend; this keeps GitHub Pages deployment and maintenance straightforward. Artistic choices and the exact activities are implementation choices within the user's request for more interactive marine features.
